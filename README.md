## 🌟 專案功能

- 🥦 1. 精選餐點與食譜
- 🛒 2. 購物車系統

## 📂 專案資料夾結構

```text
src/
├── 🧩 components/          # 通用 UI 元件
│   ├── Error.jsx           # 錯誤提示頁面
│   ├── Footer.jsx          # 頁尾版權聲明元件
│   ├── Header.jsx          # 頁首導覽列
│   └── Loader.jsx          # 載入中動畫元件

│   │   └── Cart.jsx        # 購物車頁面

│   │   ├── Doit.jsx        # 美食食譜頁面
│   │   └── Menu.jsx        # 美食介紹頁面
│   └── order/              # 訂單功能模組
│       └── Order.jsx       # 訂單詳細資訊頁面
├── 📖 pages/               # 路由對應的頁面與主要 Layout
│   ├── AppLayout.jsx       # 整體版型配置
│   ├── Contact.jsx         # 聯絡我們頁面
```
